TOCHITOLANDIA — PAQUETE PWA ACTUALIZADO

Archivos:
- index.html: app con nueva marca, paleta de colores y pug animado con CSS.
- manifest.json: nombre y apariencia al instalar.
- sw.js: caché para uso sin conexión tras la primera carga.
- icons/: iconos de la aplicación.

PUBLICACIÓN DESDE ANDROID
1. Extrae este ZIP en Mis archivos.
2. En GitHub, abre tu repositorio mi-progreso-integral.
3. Reemplaza el index.html anterior con el index.html de este paquete y sube el manifest.json, sw.js y carpeta icons actualizados.
4. En GitHub Pages activa Settings > Pages > Deploy from a branch > main > /(root).
5. Abre la URL HTTPS publicada en Chrome y elige ⋮ > Instalar aplicación o Añadir a pantalla de inicio.
6. Abre la app con internet una vez, luego prueba el modo avión.

Si GitHub ya tiene archivos anteriores, usa Upload files para subir los nuevos y confirma el commit. Comprueba que no queden archivos duplicados dentro de una subcarpeta.

Los datos personales se guardan en el almacenamiento local del navegador. Exporta una copia de seguridad regularmente. No borres los datos del navegador sin respaldarlos.
